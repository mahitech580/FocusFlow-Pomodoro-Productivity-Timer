# 🚀 FocusFlow — Pomodoro Productivity Timer

> **Focus Today • Build Tomorrow.**

**FocusFlow** is a modern Pomodoro productivity timer built with **React.js, JavaScript, Vite, and CSS3**. It combines focused work sessions, task management, productivity statistics, customizable timers, and a realistic **3D-inspired interactive interface** to create a clean and engaging productivity experience.

## ✨ Features

### 🍅 Pomodoro Timer

* 25-minute focus session

* 15-minute long break
* Start / Pause

* Session counter

* 3D-inspired timer orb

## 🚀 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/mahitech580/FocusFlow-Pomodoro-Productivity-Timer.git
```

### 2. Enter the project

```bash
cd FocusFlow-Pomodoro-Productivity-Timer
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start development server

```bash
npm run dev
```

Open the local URL shown in your terminal.

---

## 📦 Production Build

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## 🧠 Why FocusFlow?

FocusFlow is designed around a simple idea:

Instead of being just a countdown timer, FocusFlow combines time management with tasks, statistics, customization, and an interactive interface.
